Recover this account

1. New phone's key

Paste the key the phone shows, or scan its QR. 128 hex characters: qx, then qy.







  
2. Chirp with the phone

  
Open the chirp app

  
Host the session there and join from the phone. Keep this tab open.






  
3. Proofs

  
Waiting for the session.

  
If the chirp app says the proof was skipped or failed, or the session went wrong, chirp again. Nothing has been sent yet.

  






  
4. Start the recovery

  
Type the email, then press Tab. Chrome mints the token when the field loses focus.
